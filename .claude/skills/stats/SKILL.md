# 閲覧数の把握

## 1. 最新化
- `node scripts/note-stats.js` を実行し、note のスキ・コメントを最新にする（毎日自動でも動いている）

## 2. スクショの記録（添付があれば必ず）
- 画像から数字を読み取り、`content/stats/views.csv` に 1 投稿 1 行で追記する
  - date：スクショの日付（不明なら今日）、platform：note / ameblo / instagram / threads / x / tiktok
  - period：公開翌日なら d1、3 日後 d3、7 日後 d7、週の合計は week
  - note は `note-posts.csv` からタイトルで記事キーを引いて key_or_url に入れる
- 読み取れない数字は空欄にし、チャットで「読めなかった項目」を 1 行で伝える

## 3. 抜けのチェック
- 過去 14 日に公開した記事・動画で、d1 / d7 の閲覧数が views.csv に無いものを一覧にする
- 「どの画面のスクショを送ればいいか」を媒体ごとに 1 行で書く
  - note：アプリ「ダッシュボード」→ 期間「週」→ 記事一覧
  - アメブロ：アプリ「アクセス解析」→ 記事別
  - Instagram：投稿 →「インサイトを見る」
  - Threads：プロフィール →「インサイト」
  - X：ポスト →「ポストアナリティクス」
  - TikTok：動画 →「…」→「アナリティクス」

## 4. 週次レポート（日曜、または依頼時）
`content/stats/reports/YYYY-Www.md` に保存し、チャットには結論だけ返す。
1. 結論 3 行（伸びたもの・落ちたもの・来週変えること 1 つ）
2. シリーズ別：侵食図鑑（テーマ・回ごと）／小説（作品・章ごと）／台湾記事
   - note：閲覧数（views.csv）とスキ（note-posts.csv の d1 / d7）
   - 動画：TikTok・リールの再生数
3. 回を追うごとの落ち方：同じテーマ・同じ作品の中で、第1回→最終回の閲覧数の比率
4. 投稿時刻別の平均スキ
5. 来週の打ち手：すぐ使う版・少し凝った版の 2 案（変える条件は 1 つだけ）

保存したファイルはコミットして push する。
