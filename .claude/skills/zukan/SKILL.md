# 侵食図鑑 1テーマ（3回）パック

引数は神の名前。なければ `content/schedule/2026-Q4.md` の次のテーマを使う（仮定として明記）。

## 最初に
- CLAUDE.md「閲覧数は必ず把握する」に従い、`content/stats/views.csv` の抜けを確認。抜けがあればチャット冒頭で送ってほしいスクショを 1〜3 行で伝える
- 前のテーマの③起動編の数字（d1 / d7）があれば、構成や時刻の調整に使う

## 3 回の構成（1 回 1,500〜2,500 字）
| 回 | 中身 | 最後の引き |
|---|---|---|
| ①原典編 | 神話の中のその神。人物像・逸話・象徴物。侵食の「兆し」を 1 枚だけ見せる | 「この象徴物が、どう変わるのか」 |
| ②侵食編 | どこが・なぜ・どう機械化したか。部位解説 3〜4 か所（造語《》＋ふりがな） | 「その体が動き出すとき」 |
| ③起動編 | 動き出した姿と、その神の物語の続き（短い場面描写）。設定資料のまとめ。次のテーマの予告 | 次のテーマ名と開始日 |

各回の共通ルール
- タイトル 2 案（すぐ使う版／少し凝った版）。形式「神話キャラクタ侵食図鑑｜<神名>｜<回名>」
- 冒頭 3 行で前回の要約（①は「何の神が何になるか」）
- `[画像①: …]` の形で挿入位置と内容を指定
- 末尾 CTA：前回リンク、次回の公開日時、マガジン、進捗「N/12 柱」
- ハッシュタグ 5 個

## 手順
1. 連番 NN と slug を決める
2. `content/zukan/NN-<slug>-1.md` 〜 `-3.md` の 3 ファイルに、各回の成果物を保存する
3. 各ファイルの中身（見出し順）
   1. 予約表：CLAUDE.md「投稿のリズム」のテーマ週で、日付と時刻を具体的に
   2. note 記事
   3. アメブロ版：400〜600 字の要約＋note への誘導
   4. SNS 投稿文：Instagram（カルーセル 5 枚の各枚の文字）、X（140 字以内）、Threads（300 字前後、問いかけで終える）。日英ハッシュタグ
4. `-1.md` の最後に Higgsfield プロンプト（英語）をまとめる。被写体、素材の質感、ライティング、アングル、構図、色、ネガティブを明記
   - サムネ（4:5）：回ごとに 1 本ずつ計 3 本（①は原典寄り、②は侵食途中、③は完成形）
   - 動画の背景画（9:16）2〜3 本：文字を載せるので、画面中央〜上に暗く余白のある構図
   - 動くカット（9:16・5 秒）1 本：動き・カメラワーク（slow push-in、orbit など）を指定
   - 「生成したら `content/assets/zukan-<slug>/` に thumb-1.webp〜thumb-3.webp / bg-01.webp / clip-01.mp4 の名前で入れるか、チャットに画像を添付」と一文添える
5. 文字動画の台本を `content/text-videos/zukan-<slug>.json` に保存する（3 回分の要点を 6〜7 枚に。最後は「全 3 回 note で公開中」）
   - `content/assets/zukan-<slug>/` に素材があれば `npm run text-video -- <json>` で生成し SendUserFile（display: attach）で送る
   - 素材がまだなら「素材を渡したら `/text-video zukan-<slug>` で作る」と伝える
6. 予定表 `content/schedule/2026-Q4.md` と違う神を指定されたら、表を更新する
7. コミットして作業ブランチへ push
8. チャットには「結論＋予約表＋ファイルの場所」だけ短く返す
