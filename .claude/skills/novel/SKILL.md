# 侵食小説 1話パック

## 最初に
- `content/novel/_bible.md`（設定資料）を読む。無ければ先に作る
  - 仮定の初期設定：侵食図鑑と同じ世界。家電・住まい・植物が少しずつ生体機械化していく日常ホラー寄りの連作。主人公・舞台・ルールを 1 ページで
  - 作った設定はチャットで要点を見せ、違えば直すと伝える
- 既存の話 `content/novel/NN-*.md` のあらすじを確認して続きにする

## 手順
1. 連番 NN と slug を決める
2. 成果物を `content/novel/NN-<slug>.md` に保存。`_bible.md` の「これまでのあらすじ」を 2〜3 行更新
3. 台本 `content/text-videos/novel-<slug>.json`（style: novel）を作り `npm run text-video -- <json>` で生成
4. mp4 を SendUserFile で送り、コミットして push
5. チャットは「結論＋予約表＋ファイルの場所」だけ

## 成果物
1. **予約表**：CLAUDE.md の週間スケジュールで、次の木〜土の日付と時刻
2. **note 本文**：タイトル 2 案、2,000〜3,000 字、場面転換ごとに `[挿絵: …]`、末尾に次回予告とマガジン誘導
3. **アメブロ版**：冒頭 600 字＋「続きは note で」
4. **挿絵・サムネ用 Higgsfield プロンプト**（英語）2 本。図鑑より静かで文学的な画づくり（柔らかい光、生活感、違和感は一点だけ）
5. **SNS 投稿文**：Threads（本文の一節の引用＋問いかけ）、X（一文引用）、Instagram（引用画像用の文字＋キャプション）、TikTok キャプション。日英ハッシュタグ
6. **文字動画の台本**：本文から印象的な一節を 5〜6 枚。最後は「第N話 note で公開中」
