# 小説の続き

小説は毎日 1 章、21:30 に出す。図鑑のテーマ週も合間の週も止めない（CLAUDE.md「投稿のリズム」）。

## 最初に
- CLAUDE.md「閲覧数は必ず把握する」に従い、`content/stats/views.csv` の抜けを確認して、あればチャット冒頭で伝える
- 作品を決める：引数の作品名。なければ `content/stats/note-posts.csv` の category=novel から、連載中で未完の作品を最新の日付順に選ぶ（仮定として明記）
- 作品フォルダ `content/novel/<作品slug>/` を見る
  - `_bible.md` が無ければ作る：`note-posts.csv` からその作品の既存の章の記事キーを集め、`https://note.com/api/v3/notes/<key>` の body から本文を読み、登場人物・舞台・ルール・これまでのあらすじ・未回収の伏線を 1 ページにまとめる
  - あれば直近 2 章分の本文も読み、文体（一人称／三人称、改行の癖、章の長さ）を合わせる

## 成果物
`content/novel/<作品slug>/NN.md` に保存（NN は章番号）
1. 予約表：次の公開日と 21:30。アメブロ 22:00、Threads 22:00
2. note 本文：既存の章と同じタイトル形式（例「【ホラー長編】区画　第二章　○○」）、既存の章と同じくらいの長さ、末尾に次章の公開日時とマガジン誘導
3. アメブロ版：冒頭 600 字＋「続きは note で」
4. SNS 投稿文：Threads（本文の一節の引用＋問いかけ）、X（一文引用）、Instagram（引用画像用の文字＋キャプション）。日英ハッシュタグ
5. 挿絵・サムネ用 Higgsfield プロンプト（英語）2 本：静かで生活感のある画、違和感は一点だけ
6. 完結する章なら：次に連載する作品の候補 2 案（すぐ使う版＝既存の未完作品の再開、少し凝った版＝新作の 1 行あらすじ）

## 保存と動画
- `_bible.md` の「これまでのあらすじ」を 2〜3 行更新
- 週に 1 回（合間の週・テーマ週とも土曜）は、その週の章から台本 `content/text-videos/novel-<作品slug>-wNN.json`（style: novel）を作り `npm run text-video -- <json>` で生成して送る
- コミットして push。チャットは「結論＋予約表＋ファイルの場所」だけ
