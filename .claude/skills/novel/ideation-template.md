# 『<作品名>』発想メモ（_ideation.md）

プロットより先に書く。ここを飛ばして `_bible.md` を書いてはいけない。
筋の通った話を最初から作ろうとしない。不条理な仮説から始め、筋は最後に通す。

---

## 1. 逆転質問
問い：「絶対に誰も怖がらない、最も退屈で無意味な日常のルールは何か」
- 10 個以上書き出す。題材（神・テーマ）に関係なくてよい。怖くしようとしない
- 例の型：回覧板は右隣へ回す／ゴミ袋は口を二回縛る／エレベーターでは階数表示を見る

| # | 退屈なルール | その真逆の状況（ルールが逆向きに働く・誰も守らない・守りすぎる・人のほうがルールに合わせて変わる） |
|---|---|---|
| 1 | | |
| … | | |

→ 物語の起点に使う「真逆の状況」を 1〜2 個選び、理由を一行で書く

## 2. 対立仮説
「これは正しい」「疑いようがない」と思っている要素を 5 個以上挙げ、真っ向から反対の仮説を立てる。
必ず含める：
- 作品の前提（題材の置き換え方）
- 語り手は信頼できる／できない
- 誰が加害者で、誰が被害者か
- 結末の向き
- 作風のルール（例「怪物は出さない」）と、題材（神話）の通説

| 思い込み | 反対の仮説 | 検証（どちらが話を開くか／どちらが怖いか／事実と矛盾しないか） | 採否 |
|---|---|---|---|
| | | | 採用／棄却（理由） |

- 棄却した仮説も消さずに残す。後の章の伏線や別作品の種になる
- 作風のルールを破る仮説を採るときは、本人に確認してから

## 3. 不条理な仮説（起点）
1・2 から、突拍子もない仮説を 3 つ作る。説明がつかなくてよい。
- 仮説 A：
- 仮説 B：
- 仮説 C：

→ 起点にする仮説：（1 つ）
→ ここから初めて、筋を通す（`_bible.md` の骨格へ）
