# 週間予約プラン

1. CLAUDE.md「閲覧数は必ず把握する」に従い、`content/stats/views.csv` の抜けを確認して冒頭に書く
2. 対象週（指定がなければ次の月曜始まり）が「テーマ週」か「合間の週」かを `content/schedule/2026-Q4.md` で確認する
3. CLAUDE.md「投稿のリズム」をもとに、日付・媒体・時刻・使うファイルを 1 行ずつのチェックリストで出す
   - 形式：`[ ] 9/28(月) 20:00 note 予約｜content/zukan/04-persephone-1.md`
   - 小説は毎日 1 行ずつ（作品名と章番号）
   - 数字の記録も行に入れる：`[ ] 9/29(火) スクショ：note ダッシュボード（①原典編の d1）`
4. まだ無い素材（記事・画像・台本）を末尾に「制作待ち」として並べ、`/zukan` `/novel` `/text-video` のどれで作るかを添える
5. 2 案で出す：すぐ使う版（リズムどおり）、少し凝った版（前週の `/stats` で伸びた時刻・媒体に寄せた調整版）
6. `content/schedule/YYYY-Www.md` に保存してコミット・push
