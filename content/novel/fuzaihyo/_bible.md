# 『不在票』プロット（長編ホラー・全13話）

発想の記録：`_ideation.md`（起点＝仮説 A「家にいる人の家に、わたしは正しく不在票を入れつづける」）／事実確認：`factcheck.md`

## 作品の骨格
- ジャンル：日常・心理ホラー（イヤミス）。怪物・幽霊・超常は出さない。誰も規則を破らない
- 下敷き：ヘルメス。神々の使い、道案内、死者の魂を冥界へ送り届ける役（プシュコポンポス）、そして生まれた日に牛を盗み、足跡をごまかした泥棒の神
- 現代への置き換え：同じ世帯の家族が正しく届け出て、郵便局が正しく確かめると、家にいる人が「書類の上で」引っ越していく。運んだのは、配達員のわたし
- 語り手：わたし（配達員）。一人称、淡々。1 話 3,000〜3,500 字
- 話の中の時間：10 月の終わりから 12 月の初めまで（連載は 10/12〜10/24）
- 同時連載：神話キャラクタ侵食図鑑｜05 ヘルメス（10/12・10/14・10/16）

## 神話との対応
| 神話 | この作品 |
|---|---|
| 神々の使い・道案内 | 配達員。毎朝同じ道順で、全部の家を回る |
| 死者の魂を冥界へ送り届ける | キヨあての郵便（＝この町での居場所）を、転送ラベルで施設へ送る |
| 生まれた日に牛を盗み、足跡をごまかした | 書留の追跡記録。「不在のため持ち戻り」「保管期間経過」「差出人へ返還」。正しい足跡が、キヨが家にいなかったことを示す |
| 亀の甲羅で竪琴を作る／拾い物は「ヘルメスの贈り物」 | キヨの夫が道で拾った石亀。キヨが施設へ移る日に、わたしに預けられる |
| ペルセポネを冥界から連れ戻す | わたしだけが、キヨを「連れ戻す」方法を知っている（本人が窓口に行けばいい）。でも言わない |
| 使いの神は、次の使いに役目を渡す | 最終話、後輩がわたしの家に居住確認に来る |

## 仕掛け（読者だけが気づいていく）
- わたしは一度も嘘をつかない。「今日は何も来てません」は、毎回本当である（この家に配る郵便は、もう無い）
- 恵美子も嘘をつかない。「義母は施設に移りました」は、書類の上では正しい。キヨは「恵美子さんがそう言うなら、そうなんでしょう」と言う。同意したのか、忘れたのかは、最後まで決まらない
- 第11話で、わたしの「確認」が、キヨを施設に移す理由の一つとして使われていたと分かる
- 第4話・第9話で、弟が「家を売って、姉さんは駅前に」と言い、わたしは「そのうちね」と答えている。第13話で、それが同意として扱われる。キヨと同じ形
- タイトルの不在票は、第3話で一度だけ入れる。最終話で、わたしの家の郵便受けに入っているのは不在票ではなく、転居の確認書

## 事実確認が必要な点（本文を書く前に）
- 書留を同居人が受け取らない場合の扱い（作中では、受け取りを断られたので不在票を入れる、とする）
- 不在票（ご不在連絡票）の欄の文言、転送ラベル・返還の付箋の文言 → 現物の写真で確認
- 追跡サービスの表示の文言（「持ち戻り」「保管期間経過」など）→ 本文では言い換えて断定しない
- 居住確認に配達区の担当が行くかどうか → 作中の設定（`factcheck.md`）
- 入所前の人の郵便を施設が預かること → 作中の設定（施設側の好意として書く）

## 既存作との違い
- 『柘榴』は家庭裁判所と取り決め、『不在票』は郵便と住民票。どちらも「正しい手続き」で人が運ばれる
- 『柘榴』の語り手は運ばれる側の母。『不在票』の語り手は運ぶ側で、最終話に運ばれる側になる
