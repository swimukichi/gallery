## 紹介文（短い版：カクヨム紹介文・note マガジン冒頭）
```
地方の住宅地を赤いバイクで回る、期間雇用の郵便配達員の「わたし」。
ある日、八十六歳の浅井キヨさんあてに、転居届が出された。届け出たのは、同じ家に住む嫁だった。
確かめに行くと、嫁は「義母は施設に移りました」と言う。その背中の向こうに、キヨさんが立っていた。
規則では、同居人に確かめればいい。わたしは、確認書に丸をつけた。

誰も規則を破らなかった町の話です。幽霊も怪物も出てきません。
```

## あらすじ（長い版：なろう・エブリスタ・note マガジン説明）
```
地方都市のはずれ、古い住宅地を赤いバイクで回る郵便配達員の「わたし」。期間雇用で、この区を受け持って六年になる。どの家の郵便受けに誰の名前があるか、たいてい顔まで覚えている。

仕事は配るだけではない。転居届が出されると、前の住所を訪ねて、本当に引っ越したかを確かめる。本人がいなければ、同じ家の人に聞けばいい。そう決まっている。

ある日、三丁目の浅井キヨ（八十六）あてに転居届が出た。新しい住所は、市の反対側にある施設。届け出たのは、同じ世帯の嫁だった。

玄関に出た嫁は、静かに言った。「義母は、先週から施設です」。その背中の向こう、廊下の奥に、キヨさんが立っていた。

わたしは確認書に丸をつけた。翌朝から、キヨさんあての郵便は、すべて新しい住所へ運ばれていく。家にいる人の家に、わたしは不在票を入れる。

これは、誰も規則を破らなかった町の話です。グロテスクな描写はありません。
```
