## 調査の限界
- この環境からは官公庁（法務省・裁判所）のページを直接開けなかった。検索エンジンの要約で、内容が一致する複数の出典を確認した
- 条文の細かい文言は、公開前に本人が出典ページで一度確かめること
- 数字（輸入量など）は要約の段階で桁が崩れていたため、作中で使える形では確認できなかった。数字は載せていない
