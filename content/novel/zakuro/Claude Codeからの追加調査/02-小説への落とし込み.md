# 小説への落とし込み

結論：すぐ直したほうがいいのは **第12話の 1 文**と**第13話の「担当」の扱い**の 2 か所。どちらも制度の上で筋が通らなくなっている。
あとは、制度の言葉（監護の分掌・妨げてはならない）を足すと「正しく動いている人と決まりの話」が強くなる。

- 公開日：第5話 10/2、第8話 10/5、第10話 10/7、第11話 10/8、第12話 10/9、第13話 10/10
- 予約済みの話を直すときは、note に加えてカクヨム・なろう・エブリスタの予約本文も直すこと
- 番号は `01-確認できた事実.md` の見出し

## 優先度 高（筋の誤り）

### 1. 第12話「親権は、共同になったからだ」← A1・A4
- 今の本文：「週末は八階で過ごすことが多くなった。それは、取り決めに反しない。親権は、共同になったからだ。」
- 問題：共同親権になっても、交流の日以外に父の家で過ごしてよい理由にはならない。住まいや過ごし方を決めるのは取り決め（監護者・交流の内容）のほう
- すぐ使う版
```
それは、取り決めに反しない。交流の日でない日に会ってはいけない、とは、どこにも書いていなかった。
```
- 少し凝った版（由紀子の帳面の読み方と同じ論理で返される）
```
それは、取り決めに反しない。取り決めに書いてあるのは、会わなければならない日のことだけだった。会ってはいけない日のことは、一行も書いていなかった。わたしが十七時十二分を書き留めたのと、同じ読み方だった。
```

### 2. 第13話「担当　佐伯小春」（3 月 8 日）← B・C
- 問題：3 月 8 日の小春は中学 3 年。3 月 31 日が終わるまでは、光明殿（宗教法人なら同居親族の事業ではない）が小春を「使う」ことはできない
- 逆にここは「正しく動いている人たち」を見せる場所になる。光明殿は法律を破らない。4 月 1 日を待っている
- すぐ使う版（小春のせりふを 1 つ足す）
```
「四月からだって。それまでは、お手伝い」
```
- 少し凝った版（発注書そのものに書かせる）
```
担当　佐伯小春（四月一日より）

括弧の中の日付は、ワープロではなく、ボールペンで書き足してあった。尚人の母の字だった。小春が中学を出る日を、あの人は、わたしより正確に数えていた。
```
- 同じ発注書の上に、発行元を一行入れると C（経営主体）も筋が通る
```
宗教法人　光明寺　納骨堂　光明殿
```
  - 第1話の「光明殿を経営しているのは、佐伯という家だった」は、寺の家（住職の家系）と読めるので直さなくてよい。第13話でこの一行を見せれば、後から裏づけられる

## 優先度 中（制度の言葉で怖さを足す）

### 3. 第12話「半分ずつ」に正式な名前をつける ← A3・A4
- 由紀子が自分から言い出した「半分ずつ」は、制度の上では**監護の分掌（期間で分ける）**。書面の冷たい言葉で返ってくるのが、この作品の怖さに合う
- すぐ使う版（代理人の書面の一節）
```
父母は、子の監護を次のとおり分掌する。
```
- 少し凝った版（監護者の条文を、由紀子が自分のことだと気づく）
```
書面の最後に、条文が一つ引いてあった。監護をすべき者が子の居所を定めることを、他の親権者は、妨げてはならない。

妨げてはならない、の主語が、わたしであることに気づくまで、二度読んだ。
```

### 4. 第12話 高校の出願に、由紀子が自分で同意する ← A1・A2
- 共同親権になったあとの進学先は、父母二人で決める事項。由紀子は反対できた（家裁に申し立てる道もあった）。それをしなかった
- 第9話で野口さんから「市内の高校、受けるんだって？」と聞かされ、知らなかったことが分かっている。その続きとして使える
- すぐ使う版
```
一月の終わりに、代理人から書面が届いた。進学先について、ご同意をお願いします。市内の県立高校の名前が書いてあった。わたしは、署名欄に名前を書いて、印鑑を押した。反対する理由は、どこにもなかった。
```
- 少し凝った版
```
同意しない場合は、家庭裁判所が、この件について親権を行う者を定めることになります。書面の最後に、そう書いてあった。脅すような書き方ではなかった。手続きの説明だった。わたしは署名した。娘を市内に送り出す紙に、自分の字で名前を書いたのは、それが初めてだった。
```
- 注意：公立高校の願書の保護者欄の扱いは県で違い、未確認。作中では「願書」と書かず「同意書」「書面」にとどめる

### 5. 第11話 小春には、小春の弁護士がいた ← A5
- 第11話で小春は、学校から直接バスで裁判所へ行っている。由紀子の知らない手続きがある、という見せ方に使える
- すぐ使う版（報告書の一行）
```
未成年者手続代理人　弁護士　（名前）
```
- 少し凝った版
```
報告書の二ページ目に、小春の名前と並んで、知らない弁護士の名前があった。未成年者の手続代理人、と書いてあった。小春が自分で選んだのか、裁判所が選んだのかは、どこにも書いていなかった。報酬は、当事者の負担とする、とあった。当事者というのは、わたしのことだった。
```
  - 報酬は「本来は当事者の負担」。援助制度もあるので、断定しすぎない書き方にしてある

## 優先度 低（あれば深くなる）

### 6. 第10話「小春」は冬の言葉 ← E
- 第10話の最後の一文の前に足す
```
小春というのは、冬の言葉だった。春の名前ではなかった。
```

### 7. 第8〜9話 暖房の温度と補填 ← F
- 12℃→10℃に下げる流れは、10℃管理の研究があるので不自然ではない（直さなくてよい）
- 足すなら、燃料の担当者のせりふに
```
「セーフティネットの補填も、基準を超えた分だけですからね」
```
  - 由紀子が「重油が高い」を理由にしているが、補填の仕組みはある。それでも下げた、という読み方ができる

## 完結後の記事・侵食図鑑に使う素材（本文には入れない）

### 8. 「六粒」は後の時代の数 ← D
- 讃歌では 1 粒で 3 分の 1 年、オウィディウスでは 7 粒で半年ずつ。6 粒は「粒の数＝月の数」にそろえた現代の再話
- 『柘榴』の第12話で取り決めが「半年ずつ」になるのは、オウィディウスと同じ割り方
- 完結記事（10/10 以降）のあとがき案
```
ペルセポネが食べた柘榴は、昔の話では一粒です。ローマの詩人は七粒と書き、一年を半分ずつに分けました。六粒になったのは、もっと後の時代です。

『柘榴』の小春が食べたのも、六粒でした。数えたのは、母親です。
```

### 9. 見ていて、告げた者はフクロウになった ← D
- 『変身物語』では、ペルセポネが柘榴を食べるのを**見ていて告げた者**（アスカラポス）がいて、そのせいで地上へ戻れなくなり、告げた者は不吉の鳥に変えられる
- 『柘榴』でこの役にいちばん近いのは、時刻を書き留めて家裁に出した由紀子自身
- 本文には書かず、あとがきか侵食図鑑の記事で明かすと効く
```
神話には、娘が柘榴を食べるところを見ていて、それを告げた者がいます。告げたせいで、娘は地上に戻れなくなりました。告げた者は、夜にしか鳴かない鳥に変えられました。

この話の中で、それが誰だったのかは、書きません。
```
