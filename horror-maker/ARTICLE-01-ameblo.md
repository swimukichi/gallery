## 本文（すぐ使う版）

```
こんばんは、NAOです。

今日は小説の更新ではなく、ひとつ相談させてください。

いま、こんなサイトを作っています。

「怖話工房（こわばなこうぼう）」

好みを選ぶと、AI があなた専用のホラー短編を書いてくれるサイトです。

まだ公開していません。
公開するかどうか、読んでくださっている方の反応を見て決めたいと思っています。
```

```
■ どんなサイト？
```
【画像①：条件選びの画面】

```
使い方は 3 つだけです。

1．好みを選ぶ
ジャンル、舞台、主人公、結末などをボタンで選びます。
テーマも「深夜のコンビニ」「祖母の家の開かずの間」など 約 30 種類。

2．筋を確かめる
いきなり本文を書かせず、まず筋（プロット）が届きます。
「幽霊を出さない」「結末をもっと嫌に」などのボタンで、3 回まで直せます。

3．縦書きで読む
納得したら本文へ。1 章ずつ書かれていくのを、縦書きで読めます。
```
【画像②：プロットの画面】

```
■ ほかと何が違うの？

AI で小説を作るサイトは、もうたくさんあります。
なので、使う人をはっきり決めました。

「ホラー小説を読み尽くして、次の一本を探している人」です。

書く前に筋を確かめられること。
「幽霊は出さない」「救いなし」まで好みを決められること。
縦書きで、ちゃんと小説として読めること。

1 日に作れるのは 3 本まで。
そのぶん一本ずつ、ちゃんと怖くします。
```

```
■ 世界観「侵食」
```

```
もうひとつ、ここだけのものを入れました。

世界観「侵食」。
身体と機械、日用品と植物の境目が、少しずつ溶け合っていく世界です。

このブログでも載せてきた「神話キャラクタ侵食図鑑」の世界を、
小説でも選べるようにしました。
```

```
■ 私の長編も、同じやり方で

実は、連載してきた長編『善き隣人』や、いま連載中の『柘榴』も、
こういうジャンルや結末を選んで、AI に書かせたものです。

好みを言葉で決めて、筋を確かめて、何度も直す。
そのやり方を、誰でも使える形にしたのが怖話工房です。
```

## 冒頭（少し凝った版）の差し替え
「こんばんは、NAOです。」から「反応を見て決めたいと思っています。」までを、次に差し替える。

```
こんばんは、NAOです。

ホラー小説を読むのが好きで、
好きすぎて、読むものがなくなる夜があります。

「幽霊は出てこないのに、最後まで嫌な気持ちが残る、団地の話」が読みたい。
でも、そんな一本はどこにも置いていない。

だったら、作れる場所を作ろう。
そう思って、いまサイトを作りかけています。

名前は「怖話工房（こわばなこうぼう）」。
まだ公開していません。公開するかどうか、皆さんに聞いてから決めたいです。
```
