# 怖話工房 お披露目記事（note・アメブロ）

- 目的：サイトは公開しない。「こういうサイトがあったらどう思いますか？」と聞いて、反応と要望を集める
- 仮定：投稿は合間の週の火曜 10/6（火）20:00。小説（21:30）とは時間をずらす
- 画像：プレビュー版のスクショ 4 枚（① 条件選び ② プロット ③ 縦書き本文 ④ 世界観「侵食」を選んだ画面）。本文がダミーの画面は写さない。本物の見本を作ったらそれに差し替える
- 記事にリンクは貼らない（公開前のため）

---

## タイトル案
- すぐ使う版：**ホラーを読み尽くした人のための「自分専用の怖い話」を作るサイト、あったら使いますか？**
- 少し凝った版：**「もう読むものがない夜」のために、怖い話の工房を作りかけています**
- 短い版（アメブロ向け）：**こんなホラー小説サイト、あったらどう思いますか？**

## 本文（すぐ使う版）

```
こんばんは、NAOです。
いつもは note でホラー長編を連載しています。

今日は小説ではなく、ひとつ相談です。

いま、こんなサイトを作っています。
名前は「怖話工房（こわばなこうぼう）」。

好みを選ぶと、AI があなた専用のホラー短編を書いてくれるサイトです。

まだ公開はしていません。
公開するかどうかを、読んでくださっている皆さんの反応を見て決めたいと思っています。
```

### 何ができるのか

```
使い方は 3 ステップです。

① 好みを選ぶ
世界観・ジャンル・舞台・主人公・結末などを、ボタンで選びます。
テーマも「深夜のコンビニ」「祖母の家の開かずの間」「社内チャットの既読」など 30 種類から選べます。
```

```
② 筋（プロット）を確かめる
いきなり本文を書かせるのではなく、まず筋だけが届きます。
気に入らなければ「幽霊を出さない」「結末をもっと嫌に」「怖さを強める」などのボタンで、3 回まで直せます。
```
【画像②：プロットの画面】

```
③ 縦書きで読む
納得したら本文へ。1 章ずつ、目の前で書かれていきます。
縦書きと横書きを切り替えられて、テキストで保存もできます。
```

### ほかの AI 小説サイトと何が違うのか

```
AI に小説を書かせるサイトは、もうたくさんあります。
なので、はっきり対象を絞りました。

「ホラー小説を読み尽くして、次の一本を探している人」です。

・書く前に筋を確かめられる
・「幽霊は出さない」「救いなし」のように、好みを細かく決められる
・縦書きで、ちゃんと小説として読める
・1 日に作れるのは 3 本まで。そのぶん一本ずつ、ちゃんと怖くします
```

### 世界観「侵食」

```
もうひとつ、ここにしかないものを入れました。
世界観「侵食（バイオメカニカル）」です。

身体と機械、日用品と植物の境目が、少しずつ溶け合っていく世界。
「神話キャラクタ侵食図鑑」で描いてきた世界を、小説でも選べるようにしました。
```
【画像④：世界観「侵食」を選んだ画面／侵食図鑑の画像を 1 枚添えてもよい】

### 私の長編も、同じやり方で作っています

```
実は、連載してきた長編『善き隣人』や、いま連載中の『柘榴』も、
ここにあるようなジャンルや結末を選んで、AI に書かせたものです。

「怪物は出さない。正しく動いている人と、決まりの話」。
そういう好みを言葉で決めて、筋を確かめて、何度も直して書いてきました。

そのやり方を、誰でも使える形にしたのが怖話工房です。
```

### 皆さんに聞きたいこと

```
公開する前に、聞かせてください。

1. こういうサイトがあったら、使ってみたいですか？
2. 選べたらうれしいテーマや世界観はありますか？
3. 1 日 3 本までだと、少ないですか？

コメントで一言いただけるだけで、とても参考になります。
反応が多ければ、公開に向けて進めます。
```

## 本文（少し凝った版）の差分
すぐ使う版の冒頭を、次に差し替える。本文の残りは同じ。

```
ホラー小説を読むのが好きです。
好きすぎて、読むものがなくなる夜があります。

有名な作品はもう読んだ。
新しく見つけても、どこかで見た筋だった。
自分が読みたいのは「幽霊は出てこなくて、でも最後まで嫌な気持ちが残る、団地の話」なのに、
そんな一本はどこにも置いていない。

だったら、作れる場所を作ろう。
そう思って、いまサイトを作りかけています。

名前は「怖話工房」。
まだ公開していません。
公開するかどうかを、皆さんに聞いてから決めたいと思っています。
```
