# 怖話工房 お披露目用の投稿文
方針：まだ「使って」とは言わない。「こんなサイトを作っています。あったら使いますか？」と見せて、反応と要望を集める。
見せ方：画面のスクショ 3 枚（条件選び／プロット／縦書き本文）か、操作の画面録画 15 秒。リンクは貼らない（公開前のため）。
集めたいこと：使いたいか／欲しいテーマ・世界観／1日3本は少ないか

## X（すぐ使う版）
```
こういうサイト、あったら使いますか？

好みを選ぶと、AIがあなた専用のホラー短編を書く。
書く前に筋（プロット）を確かめて、
「幽霊を出さない」「結末をもっと嫌に」で直せる。
縦書きで読める。

いま作っています。欲しいテーマがあれば教えてください。
#怖話工房 #ホラー
```
## X（少し凝った版）
```
「もう読むホラーがない夜」のために、怖い話の工房を作っています。

世界観：侵食（身体と機械の境目が溶ける）
ジャンル：心理ホラー
舞台：古い団地
結末：救いなし

これだけ選ぶと、まず筋が届く。気に入ったら本文。

公開するか迷っています。あったら使いますか？
#怖話工房 #ホラー #バイオメカニカル
```
