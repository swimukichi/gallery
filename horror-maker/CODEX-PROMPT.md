# Codex に渡すプロンプト（怖話工房 お披露目の予約投稿）

前提：Codex が、NAO のアカウントにログイン済みのブラウザを操作できる環境で動くこと。
クラウドの Codex（リポジトリだけを触る環境）では、note・アメブロ・X にログインできないので実行できない。
パスワードをプロンプトに書かないこと。

---

```
あなたは NAO（note: swi0801）の投稿作業を代行するアシスタントです。
ログイン済みのブラウザを使って、次の予約投稿を行ってください。
公開ボタン（今すぐ公開）は押さず、必ず「予約」で設定してください。

■ 素材の場所（GitHub: swimukichi/gallery、ブランチ claude/funny-brown-7x3p1l）
- note 記事：horror-maker/ARTICLE-01.md の「本文（すぐ使う版）」
- アメブロ記事：horror-maker/ARTICLE-01-ameblo.md の「本文（すぐ使う版）」
- X 投稿：horror-maker/X-POSTS.md の各「すぐ使う版」

  shot-08-roadmap.png（今後の予定）

■ 原稿の扱い
- 原稿の ``` で囲まれた部分だけを本文として使う。``` 自体や「【画像①：…】」の行は本文に入れない
- 「【画像①】」などの位置に、対応する画像を挿入する
  画像① = shot-02-choose.png ／ 画像② = shot-03-plot.png ／ 画像③ = shot-04-tategaki.png ／ 画像④ = shot-05-shinshoku.png
- 文面は一字も変えない

■ 1. note（10/6 火 20:00 予約）
1. note.com で新規テキスト記事を作る
2. タイトル：ホラーを読み尽くした人のための「自分専用の怖い話」を作るサイト、あったら使いますか？
3. 見出し（### の行）は note の「大見出し」にする
4. 見出し画像：shot-01-title.png
5. ハッシュタグ：本文末尾のハッシュタグ行をタグ欄にも入れる
6. 「公開に進む」→ 予約投稿 → 2026/10/6 20:00 に設定して保存
7. 予約後のプレビュー URL（公開後の URL が分かればそれ）を控える

■ 2. アメブロ（10/6 火 20:00 予約）
1. アメブロの投稿画面で新規記事を作る
2. タイトル：こんなホラー小説サイト、あったらどう思いますか？
3. 本文をそのまま貼り、「【画像①】【画像②】【画像④】」の位置に画像を入れる
4. ハッシュタグ欄に原稿のハッシュタグを入れる
5. 公開設定 → 予約投稿 → 2026/10/6 20:00

■ 3. X（x.com の Web 版で予約）
X-POSTS.md の予約表どおりに、各「すぐ使う版」を予約する。

- 投票は予約できない場合がある。その場合は予約せず、「⑦は当日手動」と報告する
- ② への返信（記事リンク）と固定ポストは、公開後でないとできないので行わない

■ やってはいけないこと
- 予約ではなく即時公開すること
- 文面の書き換え、ハッシュタグの追加・削除
- 既存の記事・投稿の編集や削除
- 設定画面（プロフィール、パスワード、支払い）に触ること
- ログインを求められたら、自分で入力せず作業を止めて報告する

■ 最後に報告すること
- 各予約の媒体・日時・タイトル（または冒頭 1 行）の一覧
- できなかった作業と理由
- note とアメブロの記事の URL（分かる範囲で）
```
